## Commands

```bash
pnpm dev          # dev server on port 3000
pnpm build        # production build
pnpm test         # run all tests (vitest)
pnpm lint         # biome lint
pnpm format       # biome format
pnpm check        # biome lint + format check combined
```

Run a single test file: `pnpm vitest run src/lib/ciphers/rc5.test.ts`

Add shadcn components: `pnpm dlx shadcn@latest add <component>`

## Architecture

The codebase follows a strict layered dependency order — each layer may only import from layers below it:

```
Types       src/types/cipher.ts          — Algorithm enum, CipherDef interface, ConversionState
Config      src/config/algorithms.ts     — registry mapping Algorithm → CipherDef
Services    src/lib/ciphers/             — pure cipher implementations (no React)
Hooks       src/lib/hooks/useConverter.ts — all crypto state logic; no UI
Providers   src/providers/               — cross-cutting React context (ThemeProvider)
Components  src/components/              — dumb UI; receive values + callbacks only
Routes      src/routes/                  — TanStack Router file-based routes
```

**To add a new cipher:**
1. Add its enum value to `src/types/cipher.ts` → `Algorithm`
2. Implement `encrypt`/`decrypt` in `src/lib/ciphers/<name>.ts` (satisfy `CipherDef`)
3. Register it in `src/config/algorithms.ts` → `ALGORITHMS`

## Key Conventions

- **Path alias**: `#/*` resolves to `./src/*` (configured in `package.json` `imports` and tsconfig)
- **Route tree**: `src/routeTree.gen.ts` is auto-generated by TanStack Router — never edit it manually; it is excluded from Biome
- **CipherPanel** is the only smart component; all other components are pure presentational (props in, events out)
- **useConverter** tracks `lastEdited: 'plain' | 'cipher'` to know which direction to re-run crypto when the secret or algorithm changes
- **ThemeProvider** toggles the `dark` class on `<html>` — Tailwind CSS dark mode relies on this
- **Biome**: tabs for indentation, double quotes for JS/TS strings
